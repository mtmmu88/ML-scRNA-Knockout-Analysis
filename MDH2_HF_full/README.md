# MDH2心衰研究 - 完整版

## 研究假设

```
Sirt5（去乳酸化酶）
    ↓ 调控
MDH2 乳酸化修饰
    ↓ 导致
线粒体代谢紊乱
    ↓ 激活
铁死亡通路
    ↓ 引发
心梗后心衰
```

## 数据集

### Bulk数据（差异分析+机器学习）
| 数据集 | 样本量 | 类型 | 用途 |
|--------|--------|------|------|
| GSE59867 | 111例 | 心梗后心衰 | 训练集 |
| GSE57338 | 231例 | 缺血性心衰 | 验证集1 |
| GSE66360 | 99例 | 急性心梗 | 验证集2 |

### 单细胞数据（敲除分析）
| 数据集 | 物种 | 类型 |
|--------|------|------|
| GSE135310 | 小鼠 | 心梗后时间序列 |

## 运行流程

```
step00_install.R      →  安装R包
        ↓
step01_download.R     →  下载3个GEO数据集
        ↓
step02_normalize.R    →  各数据集标准化
        ↓
step03_sva.R          →  批次校正（ComBat）
        ↓
step04_diff.R         →  差异分析
        ↓
step05_ML.R           →  机器学习（114种方法）
        ↓
step06_scKnockout.R   →  单细胞敲除（可选）
        ↓
step07_enrichment.R   →  GO/KEGG富集分析
```

## 运行前准备

1. 修改每个脚本的 `setwd()` 为你的路径
2. 确保 `21.ML/refer.ML.R` 路径正确
3. 单细胞分析需要另外准备Seurat对象

## 预期输出

### 差异分析
- MDH2、SIRT5在心衰中的表达变化
- 铁死亡基因表达情况
- 火山图、热图

### 机器学习
- 114种模型的AUC比较
- 最佳模型及其使用的基因
- MDH2单独诊断价值

### 敲除分析
- 敲除MDH2后受影响的基因
- 铁死亡基因是否受影响

### 富集分析
- 是否富集铁死亡通路
- 是否富集线粒体代谢通路
